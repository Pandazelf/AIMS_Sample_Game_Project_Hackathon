An interactive educational game teaching flood preparedness and survival skills for Vietnamese communities affected by climate disasters in the Mekong Delta region.

---

## 📖 Overview

**Flood Ready** is a browser-based educational game where players learn critical flood survival skills through interactive gameplay. Experience realistic emergency scenarios, make strategic decisions about resource management, and learn life-saving flood safety lessons.

### Key Features

- ⏰ **60-second preparation phase** - Collect 8 essential survival items
- 🎒 **Strategic resource management** - Consumable and reusable items
- 🌊 **20 realistic scenarios** - 10 randomly selected each game
- ⭐ **5-star rating system** - Track your flood preparedness skills
- 💡 **Educational feedback** - Learn through consequences
- 📱 **Mobile-friendly** - Fully responsive design
- 🌐 **Bilingual** - Vietnamese/English support
- 🚫 **No installation** - Runs entirely in browser

🎯 Project Summary
Problem Statement
Vietnam faces increasingly severe flooding due to climate change, particularly in the Mekong Delta region. In 2024 alone, floods caused billions of Vietnamese Dong in damage, displaced thousands of families, and resulted in numerous preventable deaths due to lack of flood preparedness knowledge.

Solution
Flood Ready addresses this through interactive gaming that:

Teaches emergency preparedness in an engaging format
Provides safe environment to practice crisis decision-making
Delivers immediate educational feedback
Improves retention through consequence-based learning
Reaches wide audiences through browser accessibility
Educational Goals
Players learn:

Essential emergency supply identification
Proper evacuation procedures
Water contamination dangers
Medical emergency response
Resource management under crisis
Community solidarity importance
Technical Implementation
Technology: Pure HTML5, CSS3, Vanilla JavaScript
AI Tools: GitHub Copilot Chat, ChatGPT (for development)
Design: Emoji icons, CSS gradients, responsive layout
Deployment: GitHub Pages (static hosting)
Game Mechanics
15 items to choose from (9 consumable, 6 non-consumable)
20 scenarios covering diverse flood emergencies
Dynamic inventory - items consumed based on choices
5-star rating - based on safe decisions (10/10 = perfect)
High replayability - random scenario selection each game
Impact
If widely adopted, the game could:

Reduce flood-related deaths through better preparedness
Decrease disease outbreaks from contaminated water
Strengthen community resilience during disasters
Improve emergency response education
Reach millions in flood-prone Vietnamese communities
